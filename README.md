# 我是老师我是家长

面向中国大陆家庭与老师的直接连接平台。老师免费入驻，家长免费发布任务；家长需要平台协助快速筛选时，可以自愿选择 ¥18 极速筛选服务。

## 当前功能

- 首次进入先选择“我是家长”或“我是老师”
- 老师首次进入填写资料，提交后进入求贤广场
- 家长浏览老师主页和小班课程
- 家长需求免费保存并发布到求贤广场
- ¥18 极速筛选为可选项，测试阶段暂不真实扣款
- 家长和老师的联系方式都不会在公开页面直接展示
- 数据使用 D1 数据库保存
- 适配电脑和手机访问

## 在电脑上运行

需要 Node.js 22 或更高版本。打开项目文件夹的终端后运行：

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。上线前检查：

```bash
npm run build
```

## 常用修改位置

- `app/marketplace.tsx`：身份流程、页面内容、示例老师和交互
- `app/globals.css`：颜色、排版和手机适配
- `app/api/`：老师入驻与家长需求接口
- `db/schema.ts`：数据库结构
- `drizzle/`：数据库升级记录

## 使用 GitHub Desktop

1. 开始修改前点击 **Fetch origin**，有更新时点击 **Pull origin**。
2. 用 VS Code 打开本项目，修改并保存文件。
3. 回到 GitHub Desktop，填写本次修改说明，点击 **Commit to main**。
4. 点击 **Push origin** 上传到 GitHub。

不要把支付密钥、短信密钥、用户手机号或 `.env` 文件提交到 GitHub。仓库已经默认忽略环境变量、本地数据库、构建产物和临时文件。
