# 青禾家教

面向中国大陆家庭的家教信息平台。老师可免费提交一对一或小班课入驻申请，家长可浏览老师、查看小班课并发布家教需求。

## 当前功能

- 老师信息展示、科目筛选与个人主页
- 小班课程展示
- 老师免费入驻，申请资料写入数据库并等待审核
- 家长需求提交，资料写入数据库并等待支付
- 适配电脑和手机访问

## 在电脑上运行

需要安装 Node.js 22 或更高版本。打开项目文件夹的终端后运行：

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。上线前检查：

```bash
npm run build
```

## 常用修改位置

- `app/marketplace.tsx`：页面内容、老师示例、小班课和交互
- `app/globals.css`：颜色、排版和手机适配
- `app/api/`：老师入驻与家长需求接口
- `db/schema.ts`：数据库结构
- `drizzle/`：数据库升级记录

## 使用 GitHub Desktop

1. 开始修改前点击 **Fetch origin**，有更新时点击 **Pull origin**。
2. 用 VS Code 打开本项目，修改并保存文件。
3. 回到 GitHub Desktop，填写本次修改说明，点击 **Commit to main**。
4. 点击 **Push origin** 上传到 GitHub。

不要把支付密钥、短信密钥、用户手机号或 `.env` 文件提交到 GitHub。仓库已默认忽略环境变量、本地数据库、构建产物和临时文件。
